# NovaTask 🚀

A modern and powerful Task Management Dashboard built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**.

NovaTask helps individuals and teams organize tasks, track progress, manage deadlines, and stay productive through a clean and responsive interface.

---

## ✨ Features

### 📋 Task Management

* Create new tasks
* Edit existing tasks
* Delete tasks
* Duplicate tasks
* Mark tasks as completed
* Task categories
* Priority levels (Low, Medium, High)
* Due dates
* Assignee support
* Tags system

### 📊 Dashboard Analytics

* Total tasks counter
* Completed tasks statistics
* In-progress tasks tracking
* High priority tasks count
* Due soon monitoring
* Overdue task detection
* Completion percentage
* Productivity score

### 🗂 Views

* Dashboard Overview
* Task List View
* Kanban Board
* Calendar View
* Activity Feed

### 🎨 Customization

* Aurora Dark Theme
* Midnight Blue Theme
* Emerald Night Theme
* Responsive Layout
* Mobile Sidebar Navigation

### 💾 Data Persistence

* LocalStorage support
* Automatic saving
* Import tasks from JSON
* Export tasks to JSON

### ⚡ Productivity Tools

* Search tasks instantly
* Filter by status
* Filter by priority
* Sort tasks
* Hide completed tasks
* Keyboard shortcuts
* Activity tracking
